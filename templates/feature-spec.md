# 功能规格模板

复制时使用实际功能名称作为标题。先用短文写完整行为，以下字段按需要组织；简单改动可直接写进任务记录并引用现有规格，不必另建文件。

- **目标与场景**：谁在什么情况下要达到什么结果，现有做法哪里不足。
- **本轮范围**：从哪个入口开始，做到哪里为止；容易误加的内容明确放在本轮之外。
- **对象与规则**：关键术语、身份、数据权威、允许的变化，引用已有决定。
- **正常与异常行为**：成功时看到什么；重复操作、取消、失败时保留什么。
- **验收实例**：每项给出初始条件、动作和独立于实现的预期结果。标明需要哪种真实环境。
- **待决定的取舍**：只列会改变实现方向且尚未确定的选择。明确决定后回写规则并保留依据。

规格保存预期行为，不累计即时测试计数；实际结果与源码身份写在任务验证记录中。
