# 项目工具与环境参数模板

生成到 `docs/agents/tool-adapters.md`。填写本项目事实；工具分工、查询流程、失败处理及并行组织方式引用[通用协作规则](../handbook/tools-and-skills.md)，安装命令引用[开发者准备说明](../handbook/developer-setup.md)。生成后改写为实际可用的相对链接。

## 开发环境

| 项目参数 | 应填写内容 |
|---|---|
| 真实项目根 | 根目录的识别方式；可迁移文档用相对路径，需要绝对路径的工具在本次运行解析 |
| 场景 | 本地、开发服务器、容器或组合；源码位置、命令执行位置和实际验收环境 |
| 运行时与包入口 | 实际版本、锁文件、runner 与命令；尚无骨架时写待建立 |
| 数据与产物 | 测试样例、配置模板、缓存、日志、临时输出和构建产物的实际位置 |
| 进程与资源 | 服务、端口、持久数据及停止或重建入口；共享资源的协调方式 |
| 权限与影响 | 当前网络、文件与外部环境边界，实际影响记录位置；不包含秘密值 |

## 命令与验证

从真实配置核对开发、构建、静态检查、测试和必要部署的入口，写工作目录、用途与副作用。每条区分已执行、仅从配置核对、尚待建立；未存在的脚本不写成可用命令。真实宿主与外部服务验证单独记录。

## 工具绑定与状态

| 能力 | 项目参数与需要记录的事实 |
|---|---|
| 技能 | 当前有关的原技能名、来源、可取得的版本、宿主发现情况、核对日期；缺项的具体影响 |
| Context7 | 项目允许的 CLI runner/命令前缀、缓存和配置位置、实际 MCP 替代入口、查询证据与版本覆盖 |
| CodeGraph | 真实根的 `.codegraph/` 探测结果、MCP/CLI 可用性、索引与查询状态；`projectPath` 按本次根解析 |
| Herdr | 宿主要求的上下文是否满足、实际版本与入口、工作副本允许位置、会话是否实测；不写可迁移文件中的临时窗格标识 |
| 其他 MCP/CLI | 名称、用途、目标、配置与认证提供方式、当前权限及真实验证范围 |

每条分别说明“已发现、可调用、已配置、已验证”，附检查日期与范围。未检查写未验证；已经看到配置不能推导连接成功。通用方法版本与开发者安装版本分别记录。

## 项目差异与缺项

只列相对通用规则的实际例外及理由。列出当前无法执行的步骤、缺少条件、可用替代和对下一任务的影响。安装交给开发者；没有索引、无可用 Herdr 会话等情形按通用规则处理，不为表格齐全自动创建或安装。
